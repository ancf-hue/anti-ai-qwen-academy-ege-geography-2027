# 🌍 EGE Geography 2027 Trainer | Тренажёр ЕГЭ по географии 2027

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Offline Ready](https://img.shields.io/badge/Status-Offline%20Ready-green)](#)
[![Languages](https://img.shields.io/badge/Lang-RU%2FEN-blue)](#)

A free, lightweight, and secure offline web application designed to help students prepare for the **Unified State Exam (EGE) in Geography 2027**. 

This tool is part of the **[Anti-AI Shield](https://ancf-hue.github.io/)** initiative, focusing on sovereign education and digital safety without tracking or advertisements.

## ✨ Key Features / Ключевые особенности

| Feature | Description |
| :--- | :--- |
| 🌐 **Bilingual Interface** | Full support for **Russian (RU)** and **English (EN)**. Switch languages instantly with one click. |
| ⏱️ **Exam Timer** | Integrated countdown timer set to the official exam duration (**180 minutes**) with visual warnings when time is running out. |
| 📝 **Interactive Trainer** | Covers all **21 tasks of Part 1** with multiple-choice questions, explanations, and shuffled answers to prevent memorization of positions. |
| 🧠 **Part 2 Guide** | Detailed breakdowns and hints for **Tasks 22–29** (extended response), including methodological tips and self-check fields. |
| ✅ **Preparation Checklist** | A dynamic checklist to track progress across key geography topics (coordinates, climate, population, etc.). |
| 📅 **25-Day Plan** | A structured day-by-day study route tailored specifically for Grade 11 students. |
| 🔒 **Privacy First** | Runs entirely locally in your browser. No data is sent to servers. Works without an internet connection after download. |

## 🚀 How to Use / Как использовать

### Option 1: Local File (Recommended)
1. Download the `index.html` file from this repository.
2. Open it in any modern web browser (Chrome, Firefox, Edge, Safari).
3. Click the **RU/EN** button in the top right corner to switch language.
4. Start the timer and begin practicing!

### Option 2: GitHub Pages
If you want to host this online:
1. Go to **Settings** > **Pages** in your GitHub repository.
2. Select the branch `main` and folder `/root`.
3. Save. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
